# Чисто — frontend 

Frontend на React + Vite. Это самостоятельный демонстрационный интерфейс: данные сохраняются в `localStorage`, поэтому для проверки не нужен backend или база данных.

## 1. Что реализовано

### Клиент
- Просмотр каталога без авторизации.
- Фильтрация одновременно по типу уборки и диапазону тарифа за м².
- Сортировка по тарифу по возрастанию и убыванию.
- Карточка компании и услуги: описание работ, телефон, рейтинг и отзывы.
- Регистрация и вход.
- Оформление заявки: площадь, дата, время, адрес, телефон и комментарий.
- Автоматический расчёт цены: `площадь × тариф за м²`.
- Список собственных заказов и их статусы.
- Отмена только новой заявки.
- Отзыв только по собственному выполненному заказу: оценка 1–5, текст до 500 символов, один отзыв на заказ.

### Представитель клининговой компании
- Регистрация компании с неактивным профилем.
- Редактирование названия, описания и телефона.
- Добавление, изменение и удаление услуг.
- Тариф услуги задаётся за 1 м².
- Просмотр только заказов своей компании.
- Принятие или отклонение только новой заявки.
- Для отказа обязательна причина, которая видна клиенту.
- Завершение только принятого заказа.

### Администратор
- Включение и отключение компаний.
- Включение доступно только при заполненных названии и телефоне.
- Удаление услуг и отзывов из публичного отображения.
- После удаления отзыва рейтинг пересчитывается.
- Старые заказы сохраняют исходные название услуги, состав работ, тариф и итоговую цену.

## 2. Что намеренно не входит в учебный MVP

В соответствии с картой пользовательских историй и документом User Story, в этой версии нет онлайн-оплаты, комиссии, платного продвижения, календаря свободных слотов, чата, уведомлений, кабинетов уборщиков и подробной аналитики. Клиент указывает желаемые дату и время, а компания вручную принимает или отклоняет заявку. Оплата происходит напрямую компании вне приложения.

В каталоге предусмотрены два типа услуг: поддерживающая и генеральная уборка. В заказе выбирается одна услуга одной компании.

## 3. Требования

- Node.js 20 или новее.
- npm (устанавливается вместе с Node.js).

Проверить версии:

```bash
node -v
npm -v
```

## 4. Запуск

Откройте терминал в папке `frontend` и выполните:

```bash
npm install
npm run dev
```

Vite выведет локальный адрес. Обычно это:

```text
http://localhost:5173
```

Откройте адрес в браузере.

Для проверки production-сборки:

```bash
npm run build
npm run preview
```

## 6. Как проверить основной сценарий

1. Войдите как клиент: `client@demo.ru` / `demo1234`.
2. Откройте каталог, выберите услугу и нажмите «Подробнее».
3. Нажмите «Заказать эту услугу».
4. Укажите площадь, будущие дату и время, адрес и телефон. Цена пересчитывается автоматически.
5. Отправьте заявку. Она появится в «Мои заказы» со статусом «Новый».
6. Выйдите из клиента и войдите как представитель компании: `partner@demo.ru` / `demo1234`.
7. Откройте «Заказы» и примите заявку. Для проверки альтернативного сценария можно отклонить другую новую заявку, указав причину.
8. Нажмите «Отметить выполненным» у принятой заявки.
9. Выйдите и снова войдите как клиент. У выполненного заказа станет доступна кнопка «Оставить отзыв».
10. После публикации отзыва он появится в карточке компании, а рейтинг пересчитается.
